# Mohan Raj — Angular 21 Portfolio

## Run locally

```bash
npm install
ng serve
```

Open `http://localhost:4200`.

## Build

```bash
ng build
```

Production files are generated under `dist/`.

## Personalize before publishing

Update these values in `src/app/app.component.ts`:
- `email`
- `githubUrl`
- `linkedinUrl`

Add your resume as:

```text
src/assets/Mohanraj_B_resume.pdf
```

Update the education section in `src/app/app.component.html` with your real college and graduation year.

## Angular features used

- Angular 21 standalone component
- `@for` control flow
- Property/class/event binding
- Component TypeScript data model
- Angular Router provider
- Responsive CSS
- Smooth section navigation

No external UI library is required.
